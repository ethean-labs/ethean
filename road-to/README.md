# Ethean Lean Consensus roadmap

The active migration roadmap is the
[Lean Consensus migration library](./lean-consensus-migration/README.md).
It defines the protocol authority policy, clean target architecture, complete
replacement inventory, security and performance gates, observability stack,
and phase-by-phase implementation plans.

Detailed peer-client research remains local under
`bazalinacaklar/peer-client-library/`. Current `leanSpec` and matching fixture,
cryptography, and networking revisions are frozen at each phase boundary before
implementation begins.

Documents removed from this directory were superseded because they described
the previous client identity or an incompatible protocol model. Git history is
the historical record; removed documents are not implementation guidance.
