# Cut v0.1.72 milestone release (2026-11-02)

## Why

Workspace `VERSION` was already `0.1.72` while root `Cargo.toml` still said
`0.1.71`, and every operator-visible change since `v0.1.53` sat under
`[Unreleased]`. Operators needed a tagged GitHub Release with the same
changelog-plus-Binaries layout as `v0.1.53`.

## What landed

| Piece | Detail |
| --- | --- |
| [`CHANGELOG.md`](../../CHANGELOG.md) | `[Unreleased]` cut into `## [0.1.72] - 2026-11-02` |
| `Cargo.toml` | `[workspace.package] version` synced to `0.1.72` |
| Tag | Annotated `v0.1.72` on the release commit |
| GitHub Release | Notes from the changelog section; binaries via `release-binaries` |

## Scope of 0.1.72 (vs 0.1.53)

- Multi-node proving mesh (`ethean devnet-init`, `local-devnet.ps1`) that
  finalizes on one host; prover core sharing; slot-end pre-prove
- leanSpec attestation targets, aggregator subnets, once-per-slot Type-1,
  default one attestation data per block
- Live fork-choice on `config.yaml` genesis, vote retry, majority Status tip
- Checkpoint sync (`--checkpoint-sync-url`) and late-joiner catch-up
- Hive `/lean/v0` HTTP, test_driver routes, GHCR multi-arch image
- Bounded gossip/FC/serve caches so long runs do not grow ~6 MB/min
- Per-validator XMSS keys; durable `--data-dir` on the config.yaml path
