# libp2p 0.57 after Dependabot merge (2026-11-02)

`ethean-labs/ethean` #8 merged `libp2p` 0.54.1 → 0.57.0 onto `master` while
`test-lean-crates` was red. This note is the compile recovery, not a protocol
change.

## What broke

- `request_response::Codec` is RPITIT (`impl Future + Send`). `#[async_trait]`
  impls no longer match. Dropped `async-trait` from `ethean-network`.
- `request_response::Event::Message` gained `connection_id`. Match with `..`.
- Gossipsub 0.50 removed `ConfigBuilder::max_messages_per_rpc`. The Lean cap
  (`MAX_MESSAGES_PER_RPC` = 500) now goes to `max_publish_messages`.

Identity / secp256k1 PeerId derivation and QUIC listen/dial paths did not need
edits. Status, blocks-by-root, and blocks-by-range codecs stay framed Snappy on
the same `/leanconsensus/req/...` protocols.
